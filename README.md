# MS_DM

Metriplectic Symplectic Diffusion Models.

This repository contains the implementation of Metriplectic Symplectic Diffusion Models (MS_DM) for generative modeling. MS_DM combines the principles of symplectic geometry and diffusion processes to create models that respect the underlying physical laws.

GENERIC DIFFUSION MODEL REFERENCE:

- [Metriplectic Diffusion Models](https://arxiv.org/abs/2305.17110) - Paper introducing the concept of Metriplectic Diffusion Models.
